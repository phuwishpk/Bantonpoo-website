# เว็บไซต์ชุมชนบ้านต้นโพธิ์

เว็บไซต์วิสาหกิจชุมชนสมุนไพรบ้านต้นโพธิ์ หมู่ที่ 1 ตำบลบางขะแยง อำเภอเมืองปทุมธานี
จังหวัดปทุมธานี — ชุมชนไทยเชื้อสายมอญริมแม่น้ำเจ้าพระยา นำเสนอผลิตภัณฑ์สมุนไพรของชุมชน
เรื่องเล่าประวัติความเป็นมา และการท่องเที่ยวเชิงวัฒนธรรม

**สถานะปัจจุบัน** — หน้าเว็บครบทุกหน้าและใช้งานได้จริง
ข้อมูลข้อเท็จจริงเรื่องชุมชนอ้างอิงจากแหล่งที่ตรวจสอบได้ (ดูหัวข้อ "แหล่งข้อมูล")
ส่วนรายการสินค้า ราคา และรายละเอียดกิจกรรมยังเป็นข้อมูลร่าง

**ระบบหลังบ้าน (CMS)** — Payload + PostgreSQL เข้าที่ `/admin`
**ทุกข้อความและทุกรูปบนเว็บแก้ได้จากหลังบ้านแล้ว** รวมถึงเมนูนำทาง
ไม่เหลือเนื้อหาฝังอยู่ในโค้ด

---

## แหล่งข้อมูล

ข้อเท็จจริงเรื่องที่ตั้ง ประวัติชุมชน ประชากร วัดเจตวงศ์ ทุนชุมชน ปราชญ์ชุมชน
และเบอร์โทรกลุ่มวิสาหกิจชุมชน อ้างอิงจาก

- **วิกิชุมชน ศูนย์มานุษยวิทยาสิรินธร (องค์การมหาชน)** — ข้อมูลชุมชนบ้านต้นโพธิ์
  เรียบเรียงโดย กฤษฎา อุ่นลาวรรณ, 4 มกราคม 2567
- เทศบาลตำบลบางขะแยง (2564) แผนพัฒนาท้องถิ่น (พ.ศ. 2566–2570)
- สำนักงานพัฒนาชุมชนอำเภอเมืองปทุมธานี (2561) รายงานสารสนเทศสัมมาชีพชุมชนระดับหมู่บ้าน
- กันตชา ศรีอยุธย์ (2564) การศึกษากระบวนการการมีส่วนร่วมของชุมชนท่องเที่ยวโอทอปนวัตวิถีบ้านต้นโพธิ์ฯ

**ข้อมูลที่ยืนยันแล้ว:** ที่อยู่ · พิกัด 13.968369, 100.527574 · เบอร์ 08-1822-0774 ·
ชาวมอญอพยพจากเมืองเมาะตะมะ · ที่มาของชื่อชุมชน · วัดเจตวงศ์ (ขึ้นทะเบียนโบราณสถาน พ.ศ. 2530
บูรณะ พ.ศ. 2551) · ประชากร 5,870 คน 2,777 ครัวเรือน · พื้นที่เกษตร 45 ไร่ ·
ทุนชุมชน 6 รายการ · ปราชญ์ชุมชน 2 ท่าน

**ข้อมูลที่ยังเป็นร่าง (ต้องให้ชุมชนยืนยัน):** รายการสินค้าและราคา (ยกเว้นการมีอยู่ของยาหม่องน้ำ)
ส่วนผสมและปริมาณสุทธิ · รายละเอียดฐานเรียนรู้ ค่าบริการ และเวลาทำการ · LINE / Facebook / อีเมล ·
ประวัติโดยละเอียดของปราชญ์ชุมชนทั้งสองท่าน

> ⚠️ **รูปภาพ 8 รูปในไฟล์ `บ้านต้นโพธิ์.html`** เป็นลิขสิทธิ์ของเทศบาลตำบลบางขะแยงและ
> กลุ่มพลังปัญญาสัมมาชีพสมุนไพรบ้านต้นโพธิ์ **ไม่ได้ถูกนำมาใช้ในเว็บนี้**
> ใช้เป็นเพียงตัวกำหนดว่าภาพ placeholder แต่ละช่องควรเป็นรูปอะไรเท่านั้น
> หากต้องการใช้จริงต้องขออนุญาตเจ้าของภาพก่อน

## เริ่มใช้งาน

```bash
npm install
cp .env.example .env.local         # แล้วใส่ PAYLOAD_SECRET ด้วย openssl rand -hex 32
npm run migrate                    # สร้างไฟล์ฐานข้อมูล bantonpoo.db
npm run seed                       # ใส่เนื้อหาตัวอย่าง
npm run dev                        # เปิด http://localhost:3100
                                   # หลังบ้าน http://localhost:3100/admin
                                   # อยากใช้พอร์ตอื่น: PORT=4000 npm run dev
```

ฐานข้อมูลเป็น **SQLite** เก็บอยู่ในไฟล์ `bantonpoo.db` ที่รากโปรเจกต์
ไม่ต้องติดตั้งเซิร์ฟเวอร์ฐานข้อมูล · อยากเริ่มใหม่ก็ลบไฟล์แล้วรันสองคำสั่งข้างบนซ้ำ

**ขึ้นเซิร์ฟเวอร์** — โฮสต์เป็น Plesk แบบแชร์ ไม่มี SSH จึงส่งไฟล์ผ่าน FTP
คู่มือตั้งค่าครั้งแรกอยู่ที่ [docs/deploy-plesk.md](docs/deploy-plesk.md)

```bash
cp .env.deploy.example .env.deploy.local   # ใส่รหัสผ่าน FTP ครั้งเดียว
npm run deploy:init                        # ติดตั้งครั้งแรก
npm run deploy                             # อัปเดตครั้งต่อ ๆ ไป
npm run deploy:rollback                    # ย้อนกลับเวอร์ชันก่อนหน้า
```

## จะแก้เนื้อหาต้องไปที่ไหน

ทุกอย่างอยู่ใน `src/content/` — ไม่ต้องแตะไฟล์ในโฟลเดอร์ `components/`

**แก้ผ่านหน้าแอดมิน `/admin` ได้ทั้งหมด** ไม่ต้องแตะโค้ด

| อยากแก้ | เมนูในหลังบ้าน |
| --- | --- |
| เมนูบน (ข้อความ ลำดับ เมนูย่อย ลิงก์) | ตั้งค่าเว็บไซต์ → เมนูนำทาง → เมนูบน |
| ปุ่มมุมขวาบน (เปิด/ปิด ข้อความ ปลายทาง) | ตั้งค่าเว็บไซต์ → เมนูนำทาง → ปุ่มมุมขวาบน |
| ข้อความในเมนูมือถือ (หัวข้อ กล่องติดต่อ ปุ่ม) | ตั้งค่าเว็บไซต์ → เมนูนำทาง → เมนูบนมือถือ |
| คอลัมน์ลิงก์ท้ายเว็บ | ตั้งค่าเว็บไซต์ → เมนูนำทาง → คอลัมน์ลิงก์ท้ายเว็บ |
| โลโก้ ไอคอนบนแท็บเบราว์เซอร์ ชื่อย่อ และบรรทัดรองใต้โลโก้ | ตั้งค่าเว็บไซต์ → ข้อมูลชุมชน |
| เบอร์โทร LINE Facebook ที่อยู่ พิกัด เวลาทำการ | ตั้งค่าเว็บไซต์ → ข้อมูลชุมชน |
| คำค้น SEO และ Google Analytics | ตั้งค่าเว็บไซต์ → SEO และการวิเคราะห์ |
| **สี ตัวอักษร ความมน ความโปร่งของทั้งเว็บ** | ตั้งค่าเว็บไซต์ → ธีมและหน้าตาเว็บ |
| **สีพื้นหลังและสีเน้นเฉพาะบางส่วน** | เนื้อหาประจำหน้า → เลือกหน้า → ลำดับและการแสดงส่วนต่าง ๆ |
| **CSS เพิ่มเติม** (ผู้ดูแลระบบเท่านั้น) | ตั้งค่าเว็บไซต์ → ธีมและหน้าตาเว็บ → CSS เพิ่มเติม |
| **ลำดับ/ซ่อน/คอลัมน์/พื้นหลังของส่วนต่าง ๆ — ทุกหน้า** | เนื้อหาประจำหน้า → เลือกหน้า → ลำดับและการแสดงส่วนต่าง ๆ |
| สินค้า (ชื่อ ราคา สมุนไพร วิธีใช้ รูป เลข อย.) | เนื้อหา → สินค้าชุมชน |
| บทความและข่าวกิจกรรม | เนื้อหา → เรื่องเล่าและข่าว |
| ทำเนียบปราชญ์ชุมชน | เนื้อหา → ทำเนียบปราชญ์ชุมชน |
| ฐานเรียนรู้และจุดเช็กอิน | เนื้อหา → ฐานเรียนรู้ / จุดเช็กอิน |
| หมวดหมู่สินค้าและบทความ | เนื้อหา → หมวดหมู่ |
| รูปภาพทั้งหมด | เนื้อหา → คลังรูปภาพ |
| ข้อความประจำแต่ละหน้า (hero, หัวข้อ section, การ์ด, ตัวเลข) | เนื้อหาประจำหน้า → เลือกหน้า |

**หรือแก้จากหน้าเว็บตรง ๆ** — ในหลังบ้านกด "เปิดเว็บไซต์ (โหมดแก้ไข)" แล้วคลิกที่ข้อความเพื่อพิมพ์
หรือคลิกที่รูปเพื่อเปลี่ยนรูป (เลือกจากคลังหรืออัปโหลดใหม่) โลโก้และไอคอนเว็บอยู่ในเมนู "แก้ไขหน้านี้"

**โหมดสว่าง/มืดของหลังบ้าน** — ปุ่มบนแถบด้านบน (ตามเครื่อง · สว่าง · มืด) แต่ละคนเลือกของตัวเอง
| ข้อความจากฟอร์มติดต่อ | กล่องข้อความ |

**ยังต้องแก้ในโค้ด** (เป็นตรรกะ ไม่ใช่เนื้อหา)

| อยากแก้ | ไฟล์ |
| --- | --- |
| ค่าสีเริ่มต้นและรายการฟอนต์ที่เลือกได้ | `src/lib/theme.ts` + `src/app/(frontend)/layout.tsx` |
| ชื่อสถานะสินค้าและรูปแบบผลิตภัณฑ์ | `src/lib/product-labels.ts` |
| รายการหน้าที่เลือกได้ในเมนู | `src/globals/Navigation.ts` (`PAGE_OPTIONS`) |

> ⚠️ **LINE ID, Facebook, อีเมล และโดเมนใน `site.ts` ยังเป็นค่าสมมติ**
> ส่วนที่อยู่ พิกัด และเบอร์โทรเป็นข้อมูลจริงจากแหล่งอ้างอิงแล้ว

## ภาพ

ตอนนี้ยังไม่มีรูปถ่ายจริง เว็บจึงใช้ภาพตัวอย่าง (SVG) ที่สร้างจากสคริปต์
`scripts/generate-placeholders.mjs` เก็บไว้ที่ `public/placeholder/`
แต่ละภาพมีคำบรรยายมุมขวาบนบอกว่า "ควรเป็นรูปอะไร" โดยอ้างอิงจากภาพจริงที่มีอยู่ในแหล่งข้อมูล

**วิธีใส่รูปจริง** ทีละรูปได้เลย ไม่ต้องเปลี่ยนทั้งหมดพร้อมกัน

1. นำรูปจริง (แนะนำ `.webp` หรือ `.jpg`) ไปวางใน `public/images/`
2. ครอปให้ได้อัตราส่วนเดิม — ดูขนาดที่ระบบออกแบบไว้ได้จาก `src/content/placeholders.ts`
   (เช่น สินค้า 1:1, ปกบทความ 16:9, ภาพบุคคล 1:1)
3. แก้ `url`, `width`, `height` ของภาพนั้นในไฟล์ข้อมูลที่เกี่ยวข้อง

ฟังก์ชัน `img()` ใน `src/content/media.ts` คือจุดเดียวที่ประกอบข้อมูลรูป
เมื่อย้ายไป CMS จะเปลี่ยนเฉพาะฟังก์ชันนี้ให้ดึงจาก Media collection แทน

## สิ่งที่ทำไว้แล้ว

**หน้าเว็บ** — ครบทั้ง 6 หน้าตามผังที่วางไว้ รวมหน้ารายละเอียดสินค้าและบทความ
หน้าสินค้าแสดงสมุนไพรหลัก ปริมาณสุทธิ วิธีใช้เป็นขั้นตอน และคำเตือน "ใช้ภายนอกเท่านั้น"
สำหรับผลิตภัณฑ์ที่ห้ามรับประทาน

**การสั่งซื้อ** — ไม่มีตะกร้าตามที่ตกลงกันไว้ ปุ่ม "สั่งซื้อผ่าน LINE" จะ **คัดลอก
รายละเอียดสินค้า (ชื่อ รหัส ราคา ลิงก์) ไปยังคลิปบอร์ด แล้วเปิดห้องแชท LINE OA** ให้
ผู้ซื้อกดวางส่งได้ทันที เหตุผลที่ไม่ส่งข้อความอัตโนมัติคือ LINE ไม่เปิดให้เว็บส่งข้อความ
เข้าห้องแชทของ OA โดยตรง ต้องทำผ่าน Messaging API (บอท) ซึ่งอยู่นอกขอบเขต prototype

**มือถือ** — เมนู drawer, แถบสั่งซื้อติดล่างจอในหน้าสินค้า, แกลเลอรีปัดเลื่อนด้วยนิ้ว,
ตัวกรองสินค้าแบบ bottom sheet

**หน้าสินค้าชุมชน** — มีสองมุมมองสลับได้ ค่าเริ่มต้นคือ **แคตตาล็อกแบบสไลด์**
(แสดงทีละชิ้นพร้อมข้อมูลเบื้องต้น: รูปแบบ ปริมาณสุทธิ สมุนไพรหลัก ราคา สถานะ)
ควบคุมได้ด้วยปุ่มลูกศร ลูกศรบนคีย์บอร์ด การปัดนิ้ว แถบรูปย่อ และปุ่มหยุด/เล่นอัตโนมัติ
อีกมุมมองคือตารางสินค้าแบบเดิม — มุมมองที่เลือกถูกจำไว้ใน URL (`?view=grid`)
การเคลื่อนไหวใช้ CSS transition ล้วน ไม่มีไลบรารีเพิ่ม และปิดเองเมื่อผู้ใช้ตั้งค่า
`prefers-reduced-motion`

**ตัวกรองและค้นหา** — กรองฝั่งไคลเอนต์ (เปลี่ยนทันทีไม่ต้องโหลดใหม่) และซิงก์เงื่อนไข
ขึ้น URL จึงคัดลอกลิงก์ผลการกรองไปส่งต่อได้ ใช้ได้กับทั้งสองมุมมอง

**SEO** — sitemap, robots, canonical URL, OpenGraph และ JSON-LD
(`LocalBusiness`, `Product`, `Article`, `BreadcrumbList`, `TouristAttraction`)

**ชุดสี** — เขียวสมุนไพร (leaf) เป็นสีหลัก คู่กับถ่านหมึก (ink) ครีมข้าว (rice)
เหลืองทองแบบวัดมอญ (ochre) และเทาอมฟ้า (river) แก้ค่าทั้งหมดได้ที่บล็อก `@theme`
ใน `src/app/globals.css` ที่เดียว

**ภาษา** — ไทยเป็นหลัก แต่วางโครงรองรับอังกฤษไว้แล้ว ข้อความทุกตัวเก็บเป็น
`Localized` และเรียกผ่าน `t()` เมื่อจะเปิด EN ให้ทำตามขั้นตอนใน `src/lib/i18n.ts`

- [ ] รายละเอียดฐานเรียนรู้ ค่าบริการ และเงื่อนไขการจองจริง → `src/content/workshops.ts`
