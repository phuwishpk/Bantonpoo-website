# เว็บไซต์ชุมชนบ้านต้นโพธิ์

เว็บไซต์วิสาหกิจชุมชนบ้านต้นโพธิ์ ตำบลท่าช้าง อำเภอนครหลวง จังหวัดพระนครศรีอยุธยา
นำเสนอมีดอรัญญิกตีมือ เรื่องเล่าภูมิปัญญาช่างตีเหล็ก และการท่องเที่ยวเชิงวัฒนธรรม

**สถานะปัจจุบัน: prototype** — หน้าเว็บครบทุกหน้าและใช้งานได้จริง แต่ข้อมูลทั้งหมดยังเป็น
ข้อมูลจำลองที่เขียนไว้ในโค้ด (ยังไม่ได้ต่อ CMS) ดูรายการสิ่งที่ต้องทำต่อที่ท้ายไฟล์นี้

---

## เริ่มใช้งาน

```bash
npm install
npm run dev        # เปิด http://localhost:3000
```

คำสั่งอื่น

| คำสั่ง | ทำอะไร |
| --- | --- |
| `npm run dev` | รันเซิร์ฟเวอร์สำหรับพัฒนา |
| `npm run build` | สร้างไฟล์สำหรับขึ้นจริง |
| `npm start` | รันเวอร์ชันที่ build แล้ว |
| `npm run lint` | ตรวจคุณภาพโค้ด |
| `npm run typecheck` | ตรวจชนิดข้อมูล TypeScript |
| `npm run placeholders` | สร้างภาพตัวอย่างใหม่ (ดูหัวข้อ "ภาพ") |

เทคโนโลยี: Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4
ฟอนต์ IBM Plex Sans Thai (เนื้อหา) และ Noto Serif Thai (หัวเรื่อง)

---

## โครงสร้างไฟล์

```
src/
├── app/                      หน้าเว็บทั้งหมด (App Router)
│   ├── page.tsx              หน้าแรก
│   ├── about/                เกี่ยวกับชุมชน
│   ├── stories/              เรื่องเล่า + [slug] หน้าบทความ
│   ├── shop/                 สินค้าชุมชน + [slug] หน้ารายละเอียดสินค้า
│   ├── tourism/              ท่องเที่ยวและกิจกรรม
│   ├── contact/              ติดต่อเรา
│   ├── api/contact/          ปลายทางของฟอร์มติดต่อ
│   ├── sitemap.ts            แผนผังเว็บไซต์ (สร้างอัตโนมัติ)
│   └── globals.css           ชุดสี ฟอนต์ และสไตล์กลาง
├── components/               คอมโพเนนต์ที่ใช้ซ้ำ
├── content/                  ⭐ ข้อมูลทั้งหมดของเว็บ (แก้ที่นี่)
└── lib/                      ฟังก์ชันช่วย (วันที่ ราคา SEO ลิงก์ LINE)
```

## จะแก้เนื้อหาต้องไปที่ไหน

ทุกอย่างอยู่ใน `src/content/` — ไม่ต้องแตะไฟล์ในโฟลเดอร์ `components/`

| อยากแก้ | ไฟล์ |
| --- | --- |
| เบอร์โทร, LINE, Facebook, ที่อยู่, พิกัด, ข้อความหน้าแรก | `src/content/site.ts` |
| สินค้า (ชื่อ ราคา สเปก เรื่องเล่า รูป) | `src/content/products.ts` |
| บทความและข่าวกิจกรรม | `src/content/articles.ts` |
| ทำเนียบครูช่าง | `src/content/craftsmen.ts` |
| เวิร์กช็อปและจุดเช็กอิน | `src/content/workshops.ts` |
| หมวดหมู่สินค้า/บทความ | `src/content/categories.ts` |
| เมนูนำทาง | `src/lib/nav.ts` |
| ชุดสีและฟอนต์ | `src/app/globals.css` (บล็อก `@theme`) |

> ⚠️ **ข้อมูลติดต่อทั้งหมดใน `site.ts` เป็นค่าสมมติ** ทั้งเบอร์โทร LINE ID อีเมล
> Facebook และพิกัด GPS ต้องเปลี่ยนเป็นข้อมูลจริงของชุมชนก่อนเปิดใช้งาน

## ภาพ

ตอนนี้ยังไม่มีรูปถ่ายจริง เว็บจึงใช้ภาพตัวอย่าง (SVG) ที่สร้างจากสคริปต์
`scripts/generate-placeholders.mjs` เก็บไว้ที่ `public/placeholder/`
แต่ละภาพมีคำบรรยายมุมขวาบนบอกว่า "ควรเป็นรูปอะไร"

**วิธีใส่รูปจริง** ทีละรูปได้เลย ไม่ต้องเปลี่ยนทั้งหมดพร้อมกัน

1. นำรูปจริง (แนะนำ `.webp` หรือ `.jpg`) ไปวางใน `public/images/`
2. ครอปให้ได้อัตราส่วนเดิม — ดูขนาดที่ระบบออกแบบไว้ได้จาก `src/content/placeholders.ts`
   (เช่น สินค้า 1:1, ปกบทความ 16:9, ภาพช่าง 1:1)
3. แก้ `url`, `width`, `height` ของภาพนั้นในไฟล์ข้อมูลที่เกี่ยวข้อง

ฟังก์ชัน `img()` ใน `src/content/media.ts` คือจุดเดียวที่ประกอบข้อมูลรูป
เมื่อย้ายไป CMS จะเปลี่ยนเฉพาะฟังก์ชันนี้ให้ดึงจาก Media collection แทน

## สิ่งที่ทำไว้แล้ว

**หน้าเว็บ** — ครบทั้ง 6 หน้าตามผังที่วางไว้ รวมหน้ารายละเอียดสินค้าและบทความ

**การสั่งซื้อ** — ไม่มีตะกร้าตามที่ตกลงกันไว้ ปุ่ม "สั่งซื้อผ่าน LINE" จะ **คัดลอก
รายละเอียดสินค้า (ชื่อ รหัส ราคา ลิงก์) ไปยังคลิปบอร์ด แล้วเปิดห้องแชท LINE OA** ให้
ผู้ซื้อกดวางส่งได้ทันที เหตุผลที่ไม่ส่งข้อความอัตโนมัติคือ LINE ไม่เปิดให้เว็บส่งข้อความ
เข้าห้องแชทของ OA โดยตรง ต้องทำผ่าน Messaging API (บอท) ซึ่งอยู่นอกขอบเขต prototype

**มือถือ** — เมนู drawer, แถบสั่งซื้อติดล่างจอในหน้าสินค้า, แกลเลอรีปัดเลื่อนด้วยนิ้ว,
ตัวกรองสินค้าแบบ bottom sheet

**ตัวกรองและค้นหา** — กรองฝั่งไคลเอนต์ (เปลี่ยนทันทีไม่ต้องโหลดใหม่) และซิงก์เงื่อนไข
ขึ้น URL จึงคัดลอกลิงก์ผลการกรองไปส่งต่อได้

**SEO** — sitemap, robots, canonical URL, OpenGraph และ JSON-LD
(`LocalBusiness`, `Product`, `Article`, `BreadcrumbList`, `TouristAttraction`)

**ภาษา** — ไทยเป็นหลัก แต่วางโครงรองรับอังกฤษไว้แล้ว ข้อความทุกตัวเก็บเป็น
`Localized` และเรียกผ่าน `t()` เมื่อจะเปิด EN ให้ทำตามขั้นตอนใน `src/lib/i18n.ts`

## สิ่งที่ต้องทำต่อ

**รอข้อมูลจริงจากชุมชน**

- [ ] เบอร์โทร, LINE OA ID, Facebook, อีเมล, พิกัด GPS จริง → `src/content/site.ts`
- [ ] ชื่อและประวัติช่างตัวจริง → `src/content/craftsmen.ts`
- [ ] รายการสินค้า ราคา และสเปกจริง → `src/content/products.ts`
- [ ] รูปถ่ายจริงของชุมชน สินค้า และช่าง
- [ ] โลโก้จริง (ตอนนี้ใช้เครื่องหมายชั่วคราวใน `src/components/site-logo.tsx`)
- [ ] โดเมนจริง → `siteUrl` ใน `site.ts` (มีผลกับ canonical, sitemap และปุ่มแชร์)

**เฟสถัดไป: ต่อ Payload CMS**

- [ ] สร้าง collections ตาม type ใน `src/content/types.ts` (ออกแบบให้ตรงกัน 1:1 แล้ว)
- [ ] เปลี่ยนฟังก์ชัน `get*` ใน `src/content/*.ts` ให้ดึงจาก Payload แทนอาร์เรย์
- [ ] ย้าย `site.ts` ไปเป็น Global ให้แอดมินแก้เองได้
- [ ] `src/app/api/contact/route.ts` — บันทึกลง collection "Enquiries",
      ส่งอีเมลแจ้งเตือน และใส่ระบบกันสแปม (ตอนนี้แค่ตรวจข้อมูลแล้วเขียน log)

**อยากได้เพิ่มค่อยคุยกัน**

- [ ] แบ่งหน้า (pagination) เมื่อบทความหรือสินค้ามีจำนวนมาก
- [ ] หน้าโปรไฟล์ช่างรายคน
- [ ] LINE Messaging API เพื่อส่งรายละเอียดสินค้าเข้าแชทอัตโนมัติ
- [ ] Google Analytics 4 (รอ Measurement ID)
